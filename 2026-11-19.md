# 2026-11-19 – Debouncing

## Konzept
**Debouncing**

## Kurze Erklärung
Debouncing verzögert die Ausführung einer Funktion, bis eine bestimmte Zeit lang kein neuer Aufruf mehr erfolgt. So wird z. B. eine Suchanfrage erst gesendet, wenn der Nutzer kurz aufgehört hat zu tippen – statt bei jedem Tastendruck.

## Beispielcode

```ts
function debounce<T extends (...args: any[]) => void>(fn: T, delay = 300) {
  let timer: ReturnType<typeof setTimeout>;
  return (...args: Parameters<T>) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

const search = debounce((query: string) => {
  console.log('Suche nach:', query);
}, 400);

search('a');
search('an');
search('ang'); // nur dieser Aufruf wird ausgeführt
```

In Angular (RxJS):

```ts
this.searchControl.valueChanges
  .pipe(debounceTime(400), distinctUntilChanged())
  .subscribe(value => this.load(value));
```

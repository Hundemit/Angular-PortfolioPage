# 2026-11-20 – Debouncing

## Konzept
**Debouncing**

## Kurze Erklärung
Debouncing sorgt dafür, dass eine Funktion erst ausgeführt wird, nachdem eine bestimmte Zeit seit dem letzten Aufruf vergangen ist. Typisch bei Sucheingaben: Statt bei jedem Tastendruck eine Anfrage zu senden, wartet man, bis der Nutzer kurz aufhört zu tippen.

## Beispielcode

```ts
function debounce<T extends (...args: any[]) => void>(fn: T, delay = 300) {
  let timer: ReturnType<typeof setTimeout>;
  return (...args: Parameters<T>) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

const search = debounce((query: string) => {
  console.log('Suche nach:', query);
}, 400);

search('a');
search('an');
search('ang'); // nur dieser Aufruf wird nach 400 ms ausgeführt
```

In Angular/RxJS:

```ts
this.searchControl.valueChanges
  .pipe(debounceTime(400), distinctUntilChanged())
  .subscribe(value => this.load(value));
```

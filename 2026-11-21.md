# 2026-11-21 – Memoization

## Konzept
**Memoization** (Zwischenspeichern von Funktionsergebnissen)

## Kurze Erklärung
Bei Memoization merkt sich eine Funktion die Ergebnisse früherer Aufrufe. Wird sie erneut mit denselben Argumenten aufgerufen, liefert sie das gespeicherte Ergebnis, statt neu zu rechnen. Das lohnt sich bei teuren, reinen Funktionen (gleiche Eingabe → gleiche Ausgabe), z. B. rekursiven Berechnungen.

## Beispielcode

```typescript
function memoize<A extends unknown[], R>(fn: (...args: A) => R): (...args: A) => R {
  const cache = new Map<string, R>();
  return (...args: A): R => {
    const key = JSON.stringify(args);
    if (cache.has(key)) return cache.get(key)!;
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
}

const fib = memoize((n: number): number => (n < 2 ? n : fib(n - 1) + fib(n - 2)));

console.log(fib(50)); // 12586269025 – ohne Cache würde das sehr lange dauern
```

## Persönliche Notiz
In Angular begegnet mir das Prinzip bei `computed()`-Signals und reinen Pipes: Beide berechnen nur neu, wenn sich die Eingaben ändern. Das möchte ich im Portfolio gezielt für gefilterte Projektlisten nutzen.
